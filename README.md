## 📋 Sobre a Atividade

O objetivo desta atividade é desenvolver e estilizar uma página web completa voltada para o segmento de moda, seguindo o modelo fornecido e os padrões exigidos em aula.

### 📌 Requisitos do Projeto
* [x] Elaborar a página conforme o modelo (`layout_final.jpg`)
* [x] Estilizar a página conforme o modelo
* [x] Criar repositório no GitHub
* [x] Realizar pelo menos **5 commits** no repositório
* [x] Incluir um arquivo **README** descritivo
